# アクセスモデル：誰として入るか / なぜ一般メンバーに鍵が要らないか

`setup` skill の補助資料。**「鍵が無いので動きません」と言い出す前にここを読む。**

## 0. 結論だけ

**入口は4つある。鍵が要るのは、そのうち「人ではない身分」で入る2つだけ。**

| 入口 | 誰として入るか | 鍵 | 見える範囲を決めるもの |
|---|---|---|---|
| **Notion MCP** | **その人本人** | **不要** | 本人の Notion アカウントの権限 |
| **Google Drive / Sheets MCP** | **その人本人** | **不要** | 本人の Google アカウントの権限 |
| Notion Integration（ボット） | **ボット**（人ではない） | `NOTION_TOKEN` | 「接続」したページの配下だけ |
| Google サービスアカウント | **ロボットアカウント**（人ではない） | 認証 JSON | その**メールアドレス**を共有に足したものだけ |

**メンバーが日常で使うのは上の2つ。したがって秘密鍵は要らない。**
下の2つは経理スクリプトを回すときだけで、**この配布物には含まれていない。**

> **いちばん大事な性質：下2つは誰の権限も継承しない。**
> 管理者に見えるものが自動で見えるわけではなく、**明示的に共有した分しか見えない。**
> 逆に言えば、鍵を持つ人は「その身分に共有されているもの全部」に届く。だから配布を絞っている。

## 1. Notion（メンバー全員・鍵なし）

| | |
|---|---|
| 実体 | `https://mcp.notion.com/mcp`（プラグインが配っている） |
| 認証 | **本人のアカウントに紐づく OAuth** |
| 鍵 | **不要。ローカルにファイルは何も置かない** |
| 権限 | **本人の Notion アカウントそのまま。**共有されていないページは見えない |
| マシン移動 | **再設定が要る**（認可はマシンごと） |
| 前提 | **その人が hicard の Notion ワークスペースのメンバーであること** |
| 事故 | 認可時に**個人ワークスペースを選ぶ**と、繋がったのに hicard が1つも見えない |

## 2. Google ドライブ / スプレッドシート（メンバー全員・鍵なし）

| | |
|---|---|
| 実体 | `https://drivemcp.googleapis.com/mcp/v1` / `https://sheetsmcp.googleapis.com/mcp/v1` |
| 認証 | **本人のアカウントに紐づく OAuth** |
| 鍵 | **不要** |
| 権限 | **本人の Google アカウントそのまま。**共有されていないファイルは見えない |
| 前提 | **その人が `all@hicard.studio` グループに入っていること** |
| 事故 | **個人アカウントで認可する**と、繋がったのに hicard のファイルが1つも見えない |

🔴 **認可すべきアドレスは「Drive に招待されている方」で、`@hicard.studio` とは限らない。**
個人 Gmail で招待されている人が実在する。**推測せず、実際に読めるかで判定する**（`SKILL.md` の 3-3・4）。

## 3. 新メンバーに必要なことは、これだけ

| # | やること | 誰が | 鍵 |
|---|---|---|---|
| 1 | **Notion の hicard ワークスペースに招待** | 管理者 | — |
| 2 | **`all@hicard.studio` グループに追加**（個別のドライブ招待は不要） | 管理者 | — |
| 3 | Claude Code を入れて、`hicard` プラグインを導入 | 本人 | — |
| 4 | **Notion を認可**（**hicard ワークスペースを選ぶ**） | 本人 | **不要** |
| 5 | **Google Drive を認可**（**招待されているアドレスで**） | 本人 | **不要** |

**1・2 が抜けていると、4・5 が成功しても中身が空になる。**
本人の Claude は「接続成功」と言うので、**実際に1件読ませて確かめる**必要がある。

**秘密鍵は1つも渡さない。**
