# Google ドライブをつなぐ（`setup` skill の 3 で読む）

🔴 **この plugin はドライブの接続を配っていない。**理由と実測値は
`${CLAUDE_PLUGIN_ROOT}/skills/setup/troubleshooting.md` の「なぜドライブは配れないのか」。
**ドライブは claude.ai の「コネクタ」で本人が有効にする。**

🔴 **本人にも管理者にも「どのアドレスですか」と聞かない。自分で調べる。**
聞いた時点で手が止まり、返事待ちになる。**Notion は setup の 2 で通っているので、そこから引ける。**

## 3-1. その人の会社アドレスを自分で調べる

Notion の `notion-get-users` を `user_id: "self"` で呼ぶ。
返る形：`{"type":"person","id":"...","name":"<氏名>","email":"<アドレス>"}`

| self の email | どうする |
|---|---|
| **`@hicard.studio`** | **それが第一候補。**以下ずっとこのアドレスを名指しで使う |
| 個人アドレス（Notion も個人で入っている） | 返ってきた `name` で引き直す → `notion-get-users query: "<name>"`。`@hicard.studio` の行を採る |
| どちらでも見つからない | **そのときだけ**本人に「hicard のメールアドレスは何ですか」と1問聞く |

🔴 **`@hicard.studio` が常に正解とは限らない。**Drive 側を**個人 Gmail で招待されている人が実在する**。
3-3 の実測が 3-1 と食い違ったら、**3-3（実際に権限がある方）を信じる。**

**以降、`＿＿＿@hicard.studio` と伏せずに、調べた実物のアドレスを本人に見せて言う。**

## 3-2. ドライブの検索ツールが在るかを先に見る（🔴 「有効にしてください」から入らない）

```
ToolSearch  query: "+drive search files"
```

| 結果 | 何が起きているか | やること |
|---|---|---|
| 検索ツールが出てくる | コネクタが有効 | **3-3 を測る**（認可アカウントを読む） |
| 出てこない | **claude.ai のコネクタが有効になっていない**（原因は2つある） | 下の「コネクタが無い人」へ |
| `plugin:hicard:gdrive` の失敗が見えている | **0.1.6 以前の古い版が残っている** | `claude plugin update hicard@hicard-plugins` → 再起動 |

🔴 **繋がっているのにツールが出ない、が実際に起きる。**
2026-09-05 のパイロットで、**同じマシンの片方のセッションにだけコネクタのツールが出た**（実測）。
出ないことを即「未接続」と決めず、**一度 `/exit` → `claude` で入り直してから**もう一度見る。

🔴 **間違ったアカウントで**すでに繋がっている人がいる。
「有効にして許可してください」と言うと「**もうやりました**」と返って1往復ムダになる。
だから**認可 URL を渡す前に 3-3 を測る。**認可 URL が出たときだけ、こう伝える：

> 🔴 **アカウントを選ぶ画面で、必ず `<3-1 で調べたアドレス>` を選んでください。**
> そのまま進むと、**ブラウザにログイン中のアカウント（＝普段使っている個人の方）で通ります。**

### コネクタが無い人（🔴 「有効にしていない人」と「有効にできない人」を混ぜない）

**検索ツールが出てこない理由は2つあり、直せるかどうかが逆になる。**
**先に、その人がどちらの Google アカウントで Claude を使っているかを見る**（3-1 で調べたもの）。

| どちらか | 見分け方 | 直せるか |
|---|---|---|
| **A. まだ有効にしていない** | Google アカウントが **`@hicard.studio`** | ✅ **本人が有効にできる。**hicard の Workspace 側は**連携を許可済み**（2026-09-05 zono 確認） |
| **B. 組織側で止められている** | Google アカウントが **他社のドメイン** | ❌ **本人にも hicard の管理者にも直せない。**その会社の Workspace 管理者マター |

🔴 **B は想定ではなく実在する**（2026-09-05 実測）。**他社の Workspace が、セキュリティ方針で
third-party 連携を一律で止めている**ことがある。**この場合「有効にしてください」と言ってはいけない。**
有効にする画面まで到達できない。

**A のとき**（画面の順番は未実測）:

🔴 **思い出しで画面の手順を書かない。**本人にこう伝えて、管理者へ回す：

> Google ドライブは Claude Code の設定ではなく、**claude.ai 側の「コネクタ」**で繋ぎます。
> hicard 側では許可済みなので、ご自身で有効にできます。
> こちらから画面の場所までは案内できないので、管理者に「Google ドライブのコネクタを有効にしたい」と伝えてください。

**B のとき**:

> お使いの Google アカウントは **`<3-1 で調べたアドレス>`** で、
> **その組織の設定で Claude との連携が止められています。**hicard 側では解除できません。
> **ドライブ以外は普段どおり使えます。**必要なファイルは、共有していただければ読めます。

**ドライブが未接続でも、ここで作業を止めない。**Notion は setup の 2 で通っている。
**setup の 6** の完了1行に書き分ける（**Notion 側は合格として出す**）:

| どちら | 完了1行に書く | 意味 |
|---|---|---|
| A | `Drive:未接続（コネクタ待ち）` | **あとで繋がる。**管理者が追う |
| B | `Drive:利用不可（アカウントの組織側で禁止）` | 🔴 **もう追わない。**待っても変わらない |

🔴 **B を「待ち」と書かない。**永久に来ない返事を管理者が待つことになる。

## 3-3. 🔴 判定の前に、必ず認可アカウントを読む（落ちてからでは遅い）

Drive の検索ツールを `query: "owner = 'me'"` `pageSize: 1` で呼ぶ。
返ってきた `owner` が、**いま認可されている Google アカウント**。

**これは setup の 4 で落ちたときの調査ではない。繋がったと分かった時点で毎回やる。**
先に読めば、**本人が「終わった」と思う前に**、名指しで直せる。

| 結果 | 判定 |
|---|---|
| `owner` が 3-1 のアドレスと**違う** | **setup の 4** に進む前に、まず 4 の実物判定を試す。**hicard の中身が読めるなら、そのアカウントが正しい**（個人 Gmail で招待されている場合）。読めなければ繋ぎ直し（→ `${CLAUDE_PLUGIN_ROOT}/skills/setup/troubleshooting.md`） |
| `owner` が 3-1 のアドレスと**同じ** | アカウントは合っている。**setup の 4** へ進む。**そこで落ちたら `all@hicard.studio` に入っていない**（本人から管理者へ依頼。ここでは直せない） |
| **0件**（そのアカウントがファイルを1つも持っていない） | 判定できない。**setup の 4** の実物判定に任せる |

繋ぎ直しの手順と、**繋ぎ直しで本人が失うもの**は
`${CLAUDE_PLUGIN_ROOT}/skills/setup/troubleshooting.md` の「Google アカウントの繋ぎ直し」にある。
🔴 **繋ぎ直しを頼む「前」に、失うものを自分から言う。**聞かれてから答えると、
**本人は「黙って不便にされた」と受け取る。**
