# スライドの CSS メモ（作例に何が入っているか）

`example/cooking_techniques.html` を写したときに手に入る CSS の説明。
**CSS を書き換えたくなったら、その前にここを読む。**書いてある穴は全部実際に踏んだもの。

### どのクラスがどの部品か

| 部品 | クラス | 使いどころ |
|---|---|---|
| 章扉（色ベタ1枚） | `.slide.chapter` ＋ `.num` `.sub` | 話が切り替わるところ |
| 見出し＋リード | `h2` `.lede` `.big` | ふつうの1枚 |
| 通し番号 | `.meta` | **数字だけ。**章名も罫線も入れない（2026-08-31 添削で確定） |
| 定義の並び | `.rows` > `.row` > `dt` `dd` | 「AとはB」が3〜4個 |
| ◎/✗ の2列 | `.split` > `.col.ok` `.col.ng` | 向く / 向かない |
| 対の並び | `.pairs` > `.pair` | 「A × B」 |
| 補足の囲み | `.note` | 1枚に1つまで |
| 番号つき手順 | `.steps` | まとめの1枚 |

### 🔴 章ごとに色を変える

`.slide` に `data-sec="<章>"` を付けると、その章の間だけ `--acc` が変わる。
**見出しの色・上のバー・章扉の地色が全部連動する。**
**いま何の話かが色で分かるので、話の切り替えを口で説明しなくてよくなる。**

色は**題材から採る**。料理では 塩＝グレーグリーン / 冷凍＝氷の青 / 複雑＝焦がしの赤茶。
**3色以内**。増やすと章の区切りとして機能しない。

### 🔴 和文で踏んだ穴（写した CSS に入っている。消さない）

| | |
|---|---|
| `word-break:auto-phrase` | **無いと「状/態」のように単語の途中で折れる**。日本語だけの問題 |
| `.note{max-width:47em}` | **`em` は和文だと欧文の倍の幅を食う**。38em にしたら2行に折れて間延びした |
| `text-wrap:balance` | 見出しの行が極端に不揃いになるのを防ぐ |
| `.chapter .sub{max-width:36em}` | **26em だと和文で3行に折れる。**47em の件と同じ穴を章扉でもう一度踏んだ |
| `h2 + .big{margin-top:…}` | **無いと見出しと本文が「2行の見出し」に見える。**`.big` は `h2` より小さくする |
| **書体は角ゴ1本。階層はウェイトで作る** | 見出し `Hiragino Sans` の 800、本文は 400（2026-08-31 に明朝から変えた）。**webfont は CSP で落ちるので使わない** |
| 角ゴの見出しは `letter-spacing:-.012em` | **明朝の詰めのままだと和文が緩んで見える**。行間も 1.2 → 1.3 に広げる |

### 🔴 ダークで色を明るくするときは、その色を地色に使っていないか確かめる

**同じトークンを「文字色」と「地色」の両方に使うと、ダークで反転する。**

`--salt` `--ice` `--heat` を**文字用にダークで明るくした**が、`.chapter{background:var(--acc)}` が
**同じトークンを章扉の地色に使っていた。**結果、**ダークなのに章扉だけライトより明るいベタ面**になり、
`.num`（濃い文字）が地に沈んで読めなくなった。

**直し方：地色専用のトークンを分ける。**

```css
--salt:#5E6F66;     /* 文字用。ダークで明るくする */
--salt-bg:#5E6F66;  /* 地色用。両テーマで変えない */
```

**章扉はライトでもダークでも同じ深い色＋白文字。**テーマで反転しないものは、反転させない。
