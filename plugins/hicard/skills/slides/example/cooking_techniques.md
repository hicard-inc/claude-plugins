## S2 1｜生肉には塩を振れ

**塩＝体に悪い**。このイメージがあまりにも強い。

今まで人々は、塩を使って食べ物を保存してきた。適切な量であれば問題ない。

## S3 塩をふるべき理由

| | |
|---|---|
| **日持ちする** | 水分が抜けて、**微生物が活動しにくくなる**。軽く振っただけで冷蔵4,5日持つようになる。 |
| **柔らかくなる** | 肉のタンパク質（ミオシン）が塩で溶けて、**肉が柔らかくなる**。ジューシーな仕上がりに。 |
| **うま味が立つ** | 塩気が肉全体に広がり、**肉のうま味を感じやすくなる**。大量の塩を用いれば熟成も可能。 |

## S4 塩の量

**300g に、ひとつまみ。**

🔴 **怖かったら「これ薄いよな」くらいで大丈夫。**

## S5 2｜冷凍庫を味方につけろ

## S6 冷蔵庫は「毎日買い物する人」向けにできている

**今の冷蔵庫の形は、専業主婦が当たり前だった時代の設計。**
冷蔵室が広くて冷凍室が小さいのは、**毎日買って毎日使う**前提だから。

## S7 迷ったら冷凍でいい

使い切れずに**捨てるほうが、よっぽど損をしている**。

## S8 冷凍していいもの / だめなもの

| ◎ 向く | ✗ 向かない |
|---|---|
| 肉・魚（下味をつけてから） | **こんにゃく**（水が抜けてスカスカになる） |
| ごはん・パン | **豆腐**（同上。凍み豆腐になる） |
| きのこ（**うま味が増える**） | **生のレタス・きゅうり**（砕ける） |
| ねぎ・生姜・にんにく | **大根・ごぼう**（ぼそぼそになる） |
| だし・スープ | **ゆで卵**（白身がゴムになる） |
| バター・チーズ | マヨネーズ・生クリーム（分離する） |

**見分け方：食感が持ち味のものは、冷凍に向かない。**

シャキシャキ・プリプリ・なめらか。**それを目当てに食べているものは、凍らせると別物になる。**

## S9 解凍は案外適当でも大丈夫

冷蔵庫でゆっくり解凍が一番だけど、**急ぐ場合は気にせずフライパンへ**。

## S10 3｜困ったら複雑にしろ

## S11 人は複雑さを「うまい」と感じる

**うま味には相乗効果がある。**

- グルタミン酸（昆布・トマト・チーズ）× イノシン酸（肉・魚・かつお節）→ **7〜8倍**
- そこにグアニル酸（干し椎茸）を足す → **約30倍**

## S12 定番料理は、すでに掛け算になっている

| 料理 | 掛け算 |
|---|---|
| **合わせだし** | 昆布 × かつお節 |
| **ミートソース** | トマト × ひき肉 |
| **カルボナーラ** | チーズ × 豚肉 |
| **中華スープ** | 干し椎茸 × 鶏 |

**いま作っている料理に、逆の系統をひとつ足すだけ。**

## S13 味だけじゃない

複雑さは、味覚だけで作らない。

| 軸 | 足すもの |
|---|---|
| **香り** | 仕上げの油・こしょう・柑橘・ハーブ・焦がし・生のままで |
| **食感** | 火入れ加減・切り方・サイズ |
| **温度** | たとえば、カレーライスのライスは熱すぎない方がいい |

## S14 シンプルな料理ほど難しいのはこれが理由

**素材が2つしかない料理は、複雑さを足す場所が無い。**
だから、素材そのものと火の入れ方だけで勝負することになる。

**要素を増やせばおいしくなる。**
